# 스코어북 · 농구 경기 라이브 기록기

벤치 기록담당이 경기 중에 점수와 스탯을 기록하고, 누구나 6자리 경기 코드로 실시간 점수를 볼 수 있는 웹앱이에요.

- 주소: https://kimnui1977-boop.github.io/basketball-scorebook/
- 저장: Firebase Firestore (실시간 동기화, 오프라인이면 연결될 때 자동 업로드)

## 쓰는 법
1. 오른쪽 위 **관리자 로그인** → 비밀번호 입력 (기록하는 기기에서 한 번만)
2. **새 대회 만들기** → 대회명, 경기 방식, 우리팀, 선수 명단
3. 대회 안에서 **경기 추가** → 상대팀만 쓰고 **기록 시작**
4. 선수 등번호를 누르고 → 기록 버튼. 실수하면 **되돌리기**
5. **경기 종료** → 결과, MVP, 박스스코어 복사

보는 사람은 로그인 없이 홈에서 `#코드`, 대회명, 팀명으로 검색하면 돼요.

## 컴퓨터 모드 + 키보드
오른쪽 위 **컴퓨터 모드**를 켜면 (큰 화면 + 마우스면 자동으로 켜져요) 선수 목록 · 기록 버튼 · 로그가 3단으로 펼쳐지고 키보드로 기록할 수 있어요.
한/영 상관없이 키 위치로 동작해요.

**오른쪽 키패드로 선수 번호 두 자리 → 동작 키 → `Shift`로 기록.** 한 자리 번호는 `07`처럼 0을 붙여요.
예: 키패드 `2` `2` → 위쪽 `3` → `+` → `Shift` = #22 3점 성공 · 키패드 `0` `7` → `Space` → `Shift` = #7 파울

동작 키까지 누르면 화면 위 주황 막대에 무엇이 기록될지 보이고, `Shift`를 눌러야 실제로 기록돼요. 다른 동작 키를 누르면 바뀌고, `Esc`로 취소해요.

| 키 | 동작 |
|---|---|
| 위쪽 `1` / `2` / `3` | 자유투 / 2점 / 3점 시도 (3x3: 1점슛 / 2점슛 / 자유투) |
| 위쪽 `+` / `-` | 방금 고른 시도 성공 / 실패 |
| `↑` / `↓` | 공격리바 / 수비리바 |
| `Q` `W` `E` `R` | 어시스트 · 스틸 · 블록 · 턴오버 |
| `Space` | 파울 |
| `Shift` | 고른 동작 기록 |
| `Ctrl+Z` | 되돌리기 (이 기기 기록만) |
| `Esc` | 선택 취소 |

**선수를 고르지 않고** 누르면 상대팀 기록이에요: 위쪽 `1` `2` `3` = 상대 득점, `Space` = 상대 파울 (이것도 `Shift`로 기록).
마우스로 버튼을 누르면 바로 기록돼요.
타임아웃 · 쿼터 넘기기 같은 나머지는 마우스로 눌러요. 키를 꾹 눌러도 한 번만 들어가고, 한/영 · NumLock 상태와 상관없이 동작해요.

## 갤럭시 탭에 앱처럼 설치
크롬으로 주소 열기 → 오른쪽 위 ⋮ → **홈 화면에 추가** (또는 **앱 설치**). 그러면 주소창 없이 전체 화면으로 열려요.
경기장 가기 전에 인터넷 되는 곳에서 한 번 열어 두면, 와이파이가 끊겨도 앱이 열리고 기록은 나중에 올라가요.

## 관리자 비밀번호 바꾸기
Firebase 콘솔 → Firestore → **규칙** 탭 → `request.resource.data.pin == '0000'` 의 숫자를 바꾸고 **게시**.
예전 비밀번호로 로그인해 둔 기기까지 끊으려면 Firestore **데이터** 탭에서 `admins` 컬렉션을 지우면 돼요.
(비밀번호는 보안 규칙 안에만 있고 이 저장소 코드에는 없어요.)
